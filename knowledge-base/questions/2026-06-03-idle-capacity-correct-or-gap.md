# QUESTION 2026-06-03 — is the champion's ~90% idle capacity correct, or a conversion gap?

The idle-source probe (1922 turns) shows the champion fires ~1 of ~13 eligible
planets/turn — ~90% sit idle even in close mid-game. This refuted the
"source-saturated" premise that closed the joint-coordination axis (that null was
measured only in blowout wins), so the question is genuinely open again:

- If the idle capacity is **correct hoarding** (committing those ships loses
  garrison/defense EV), then coordination has little to work with and the axis
  stays closed for the right reason.
- If it's a **conversion gap** (the agent can't find productive uses for ready
  ships), coordination / multi-turn teamwork could convert it to lift.

Evidence so far leans "mostly correct": the region advance pass — one heuristic
that *did* redeploy idle rear mass — came back net-neutral. But that's a single
redeploy rule, not a real test of coordinated deployment. **Next probe:** before
rebuilding any coordination machinery, measure whether forcing idle ships into
*the rollout's own top-ranked* secondary launches (not a heuristic target) gains
or loses EV — that isolates "no good use" from "heuristic picked wrong." Size with
PI first (Rule 26).
